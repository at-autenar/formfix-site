FormFix サポート

設定方法、動作しない場合の確認事項、不具合の報告方法を記載しています。

初期設定

  1. FormFixアプリを起動します。
  2. 画面の案内からSafariの設定を開きます。
  3. 「機能拡張」でFormFixを有効にします。
  4. SafariでWebフォームを開きます。

動作しない場合

  • Safariの機能拡張設定でFormFixが有効か確認してください。
  • 対象WebサイトでFormFixのアクセスが許可されているか確認してください。
  • SafariツールバーのFormFixメニューで、そのサイトが停止状態になっていないか確認してください。
  • ページを再読み込みしてください。
  • FormFixアプリとSafariを終了し、再度起動してください。

iframe、contenteditable、closed Shadow DOM、サイト独自の特殊な入力部品など、一部のフォームには対応できない場合があります。

FormFixが変更するタイミング

FormFixは入力値を自動で変更しません。候補を確認し、「修正」または確認画面での適用を選んだ場合だけ変更します。フォームを自動送信することもありません。

架空データだけを使った動作確認ページで候補表示を確認できます。

保存プロフィールの削除

FormFixアプリの「プロフィール」を開き、「すべて削除」を選択してください。確認後、端末内に保存されたプロフィールを削除します。

不具合を報告する

SafariツールバーのFormFixからページ診断を開くと、入力値を含まない匿名情報を確認してコピーできます。FormFixが報告を自動送信することはありません。

お問い合わせ時は、可能な範囲で次の情報を添えてください。

  • FormFix、iOSまたはmacOS、Safariの各バージョン
  • 問題が発生したページのURL（queryや個人情報は削除）
  • ページ診断でコピーした匿名情報
  • 問題が起きるまでの操作手順

氏名、住所、電話番号、メールアドレス、パスワード、カード情報は送らないでください。

お問い合わせ

GitHub Issues（github.com/at-autenar/formfix-site/issues）からお問い合わせください。公開される場所のため、個人情報や機密情報は投稿しないでください。
